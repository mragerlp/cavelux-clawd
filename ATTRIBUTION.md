# Attribution and provenance

The original Clawd character was supplied by the user and is attributed to
Anthropic. Cavelux Clawd is a CAVELUX adaptation for internal motion graphics,
showreels, and agent-avatar experiments. The user's creative brief describes it
as a tribute to Claude Code and FABLE's role in the CAVELUX workflow.

This repository does not grant a new license over the underlying Clawd character,
Anthropic branding, or other third-party material. It does not imply Anthropic
endorsement. There is no blanket open-source or public-domain license for the
combined artwork in this repository.

production systems or evidence of agent activity.
